# חיבור לרשות המסים למספרי הקצאה

מספרי הקצאה עם תוכנת ההתקנה או בהתקנה עצמית: מה כל דרך דורשת, איך מתחברים, וההתחברות מחדש כל 90 יום.

עודכן 2026-10-17

חשבונית מס לעוסק מורשה ישראלי מעל הסף צריכה מספר הקצאה מרשות המסים. עם חיבור, הלדג'ר מבקש את המספר כשמסיימים את החשבונית ומדפיס אותו על המסמך.

עוסק פטור לא מוציא חשבוניות מס, ולכן לא צריך חיבור. מתחברים כשעוברים לעוסק מורשה.

## שתי דרכים להתחבר

| | עם תוכנת ההתקנה | התקנה עצמית מקוד המקור |
| --- | --- | --- |
| אפליקציית API ברשות המסים | האפליקציה המאושרת של MTN. אין מה לבקש | נרשמים בפורטל המפתחים, מבקשים אפליקציה משלכם ומחכים לאישור |
| Client id ו-secret | אין. תוכנת ההתקנה מגדירה את החיבור | שומרים אותם כסודות ב-Worker |
| פניות מישראל | תמיד, דרך הנתיב הישראלי של MTN | רשות המסים חוסמת פניות מחוץ לישראל. לפעמים תופסים את מרכז הנתונים של Cloudflare בתל אביב, או מפעילים ממסר משלכם על שרת בישראל |
| זמן הקמה | חלק מההתקנה של 3 דקות | שעות, ועוד זמן המתנה לאישור |
| עלות | כלול במחיר תוכנת ההתקנה | חינם, ועוד שרת אם מפעילים |

## עם תוכנת ההתקנה

1. בלדג'ר פותחים **ITA** בתפריט הצד.
2. לוחצים **Connect to ITA**.
3. נפתח עמוד הכניסה של רשות המסים. נכנסים עם המשתמש של העסק ברשות המסים: קוד המשתמש והקוד החד פעמי שמגיע לטלפון.
4. מאשרים את הבקשה. מסך ההסכמה מציג את האפליקציה של MTN. חוזרים ללדג'ר, והעמוד מציג **Connected** עם מספר הימים שנשארו.

## התקנה עצמית

1. נרשמים בפורטל המפתחים של רשות המסים ויוצרים אפליקציית API לחשבוניות ישראל. מחכים לאישור לסביבת הייצור.
2. שמים את ה-client id וה-secret של האפליקציה בסודות של ה-Worker, לפי [מדריך ההתקנה](https://github.com/matanlevanon/open-ledger-il/blob/main/docs/deploy.md).
3. פותרים את חסימת הפניות מחו"ל. בעמוד ITA לוחצים **Check route**. "Direct (from TLV): reached the ITA" אומר שהפנייה עברה הפעם. "From FRA: turned away, HTTP 403" אומר ש-Cloudflare הריץ אתכם מפרנקפורט. לפניות שעובדות תמיד, מפעילים את הממסר מ-`tools/ita-relay` על שרת עם כתובת ישראלית, למשל התוכנית החינמית של Oracle Cloud בירושלים.
4. אחר כך **Connect to ITA** כמו למעלה.

בלי אפליקציה בכלל? הלדג'ר עובד גם במצב ידני: כל חשבונית שצריכה מספר מחכה בעמוד ITA, מבקשים את המספר באתר של רשות המסים ומקלידים אותו בחזרה.

[לרכישת תוכנת ההתקנה](https://open-ledger.dev/help/install/) ודילוג על שלבים 1 עד 3.

## כל 90 יום

הכניסה לרשות המסים תקפה 90 יום בשתי הדרכים. עמוד ITA מציג **Login ends in N days**. עם התראות Slack, הלדג'ר מזהיר בימים 75, 85 ו-89. כשהיא נגמרת, פותחים **ITA** ולוחצים **Connect again**. חשבונית שעדיין מחכה למספר מופיעה ב-**Allocation queue** באותו עמוד. אחרי ההתחברות לוחצים **Retry now**.

## כשמספר נדחה

עמוד ITA מציג את הסיבה. האפשרויות הן לבטל את החשבונית, להמשיך בלי מספר עם הודעה על המסמך, או לעבור לחיוב עצמי (reverse charge) בהסכמת הלקוח. שאלו את רואה החשבון מה מתאים.

עדיין תקועים? [כתבו לנו מעמוד המחירים.](https://open-ledger.dev/pricing/#setup)
