# Open Ledger IL למשרדי רואי חשבון

ניהול הספרים של כל הלקוחות בלדג'ר אחד, בחשבון Cloudflare של המשרד. כל לקוח הוא עסק נפרד, עם מספור, מפתח חתימה, קבצים ובעלים משלו.

מהדורת המשרד

## בנויה ללקוחות רבים

בוחרים בה בתוכנת ההתקנה בסימון אחד. התוכנה היא אותה Open Ledger IL, הרשומה ברשות המסים.

### כמה לקוחות שצריך

עוסקים פטורים, עוסקים מורשים וחברות, כל אחד עסק נפרד עם מספר עוסק ומספור רציף משלו.

### הפרדה בין לקוחות

בעלים של לקוח ניגש לעסק שלו בלבד. בדיקה אוטומטית עוברת על כל נתיב בכל גרסה.

### עמוד לקוחות אחד

מועד ותשלום מע"מ או ניצול התקרה, החיבור לרשות המסים, תוקף תעודות, דרישות תשלום פתוחות והוצאות לבדיקה.

### כל לקוח חותם בשמו

מפתח חתימה לכל עסק, כך שכל PDF נושא את שם הלקוח עצמו.

### הצוות שלך, בהרשאה אחת

מנהלים, עוזרים ורואי חשבון לקריאה בלבד ניגשים לכל לקוח, קיים ועתידי.

### לקוח שעוזב לוקח הכול

ייצוא לפי שנה, לדג'ר חדש ממשיך את המספור, והספרים נשמרים אצלך לתקופת השמירה.

## מי ניגש למה

| אדם | ניגש ל |
| --- | --- |
| מנהל לדג'ר | כל עסק כבעלים, וההגדרות של כל הלדג'ר |
| איש צוות, עוזר | כל עסק: לקוחות, מסמכים, שליחה, הוצאות. בלי הגדרות |
| איש צוות, רואה חשבון | כל עסק, קריאה בלבד, לפי ההרשאות שקבעת |
| בעלים של לקוח | העסק שלו בלבד |

## מהדורת המשרד והמהדורה האישית

| | אישית | משרד |
| --- | --- | --- |
| עסקים | תיק עוסק אחד, ועוד חברות | כמה שצריך, מכל סוג |
| הגדרות של כל הלדג'ר | כל בעלים | מנהלי לדג'ר בלבד |
| גישת צוות | הרשאה לכל עסק בנפרד | הרשאה אחת לכל הלקוחות |
| מפתח חתימה | מפתח אחד, או אחד לכל עסק | אחד לכל לקוח |
| עמוד לקוחות | לא | כן |
| תוכנית Cloudflare | התוכנית החינמית מספיקה | Workers Paid, $5 לחודש |

## כמה זה עולה

- המחיר למשרד נקבע לפי מספר הלקוחות. דברו איתנו.
- Cloudflare גובה ממך ישירות: Workers Paid מ-$5 לחודש, ומושבי Cloudflare Access מעל 50 משתמשים. כל מי שנכנס הוא מושב אחד.
- המידע של הלקוחות נשאר בחשבון Cloudflare של המשרד. ל-MTN אין עותק.
